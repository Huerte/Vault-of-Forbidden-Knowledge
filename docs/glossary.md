# Glossary: Plain-English Definitions for Common Terms

## Overview

The guides in this vault use words like **port**, **PATH**, and **branch** without stopping to explain them. This page defines those terms once, in plain English, so every guide can stay short.

Definitions are deliberately informal. When you need the full story, the guide that uses the term is the place to look.

## Terms

**Branch (Git)** — A separate line of work in a Git repository. You can make changes on a branch without touching the main copy until you are ready to merge them back.

**Commit** — A saved snapshot of your changes in Git. Each commit has a message describing what changed, and you can go back to any earlier snapshot.

**DNS (Domain Name System)** — The internet's phone book. It translates names like `github.com` into the numeric addresses computers actually use to talk to each other.

**Environment variable** — A named value that your operating system keeps available to every program, such as where to find temporary files. Programs read them to learn about their surroundings.

**Firewall** — A filter that decides which network connections are allowed in or out of your computer. When something cannot connect, an over-strict firewall is a common suspect.

**Fork** — Your own copy of someone else's GitHub repository. You can change your fork freely, then send the changes back as a pull request.

**IP address** — The number other computers use to reach yours on a network, for example `192.168.1.42`. Every device on your local network has one.

**PATH** — An environment variable listing the folders where your system looks for programs. If a command is "not recognized" after installing it, it usually means its folder is not on the PATH.

**Port** — A numbered door on an IP address where a specific service listens. Web servers usually use port 443 for HTTPS, SSH uses 22.

**Pull request (PR)** — A proposal to merge the changes from one branch (often your fork) into another repository. Maintainers review it, comment, and then accept or close it.

**SSH key** — A pair of files (private and public) that lets you prove your identity to a server without a password. You keep the private half secret and upload the public half to services like GitHub.

**Terminal** — A window where you type commands to the operating system directly. On Windows this is PowerShell or Command Prompt; on macOS it is Terminal.

**Two-factor authentication (2FA)** — Logging in with a second proof in addition to your password, such as a code from an app or a security key. It keeps your account safe even if the password leaks.
