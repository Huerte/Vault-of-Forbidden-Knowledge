# Visual Studio Code Shortcuts Cheatsheet (Quick Reference)

A simple, practical reference sheet for the most useful VS Code keyboard shortcuts across Windows/Linux and macOS.

## 1. General & Navigation

```text
Ctrl + Shift + P (Cmd + Shift + P on macOS)       # Open Command Palette (access all settings & commands)
Ctrl + P (Cmd + P on macOS)                       # Quick Open (navigate directly to any file by name)
Ctrl + , (Cmd + , on macOS)                       # Open Settings
Ctrl + B (Cmd + B on macOS)                       # Toggle Primary Side Bar (show/hide file tree)
Ctrl + \ (Cmd + \ on macOS)                       # Split editor pane side-by-side
```

## 2. Line Manipulation & Code Editing

```text
Alt + Up / Down (Option + Up / Down on macOS)     # Move current line or selection up or down
Shift + Alt + Up / Down (Shift + Option + Up/Down)# Duplicate current line above or below
Ctrl + Shift + K (Cmd + Shift + K on macOS)       # Delete entire current line
Ctrl + Enter (Cmd + Enter on macOS)               # Insert a new line below without breaking current line
Ctrl + Shift + Enter (Cmd + Shift + Enter)        # Insert a new line above
Ctrl + / (Cmd + / on macOS)                       # Toggle line comment
```

## 3. Multi-Cursor & Selection

```text
Ctrl + D (Cmd + D on macOS)                       # Select next match of the currently highlighted word
Ctrl + Shift + L (Cmd + Shift + L on macOS)       # Select all occurrences of current selection
Alt + Click (Option + Click on macOS)             # Insert secondary cursor at click location
Ctrl + U (Cmd + U on macOS)                       # Undo last cursor or selection addition
```

## 4. Search & Find in Files

```text
Ctrl + F (Cmd + F on macOS)                       # Find in current active file
Ctrl + H (Cmd + Option + F on macOS)              # Find and Replace in current file
Ctrl + Shift + F (Cmd + Shift + F on macOS)       # Search text across all files in workspace
Ctrl + Shift + H (Cmd + Shift + H on macOS)       # Replace text across all files in workspace
```

## 5. Integrated Terminal

```text
Ctrl + ` (Ctrl + ` on macOS)                      # Toggle integrated terminal panel
Ctrl + Shift + ` (Cmd + Shift + ` on macOS)       # Create a new terminal instance
```
