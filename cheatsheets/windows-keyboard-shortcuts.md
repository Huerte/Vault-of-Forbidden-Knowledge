# Windows Keyboard Shortcuts Cheatsheet
#windows #keyboard #shortcuts #productivity

A quick reference for shortcuts that work across the Windows desktop. Some shortcuts vary by Windows version, keyboard, or app.

## Windows and desktop

| Shortcut | What it does |
|---|---|
| `Win + D` | Show or hide the desktop. |
| `Win + E` | Open File Explorer. |
| `Win + I` | Open Settings. |
| `Win + L` | Lock the PC. |
| `Win + R` | Open the Run dialog. |
| `Win + S` | Open Search. |
| `Win + Tab` | Open Task View. |
| `Win + Ctrl + D` | Create a virtual desktop. |
| `Win + Ctrl + Left/Right` | Switch to the virtual desktop on the left or right. |
| `Win + Ctrl + F4` | Close the current virtual desktop. Open windows move to another desktop. |

## Windows and windows

| Shortcut | What it does |
|---|---|
| `Alt + Tab` | Switch between open windows. Keep holding Alt and press Tab to move through them. |
| `Win + Left/Right` | Snap the active window to the left or right side of the screen. |
| `Win + Z` | Open Snap Layouts. |

## Capture and clipboard

| Shortcut | What it does |
|---|---|
| `Win + Shift + S` | Select an area to capture with Snipping Tool. |
| `Win + V` | Open clipboard history. Turn it on when Windows prompts you the first time. |

[Microsoft's full Windows keyboard-shortcut reference](https://support.microsoft.com/en-us/accessibility/windows/keyboard-shortcuts-in-windows) covers more shortcuts and notes where behavior varies.
